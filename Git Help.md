# Подсказка по GIT

*Создание репозитория*

```sh
git init
``` 

```sh
git add
```

```sh
git commit -m "Message text"
```

```sh
git log --oneline
```
Перемещение по веткам 
```sh
git checkout <имя_ветки>
```

Отображение всех веток 
```sh
git branch
```
Создание новой ветки 
```sh
git branch <имя_ветки>
```
```sh
git branch -d <имя_ветки>
```
