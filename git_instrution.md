# Инструкция по работе с Git

## Что такое Git?
Git - это одна из реализаций распределенных систем контрол версия, имеющая как и локальные, так и удаленные репозитории. Является самой популярной реализацией систем контроля версий в мире.

## Подготовка репозитория
Для создания репозитория необходимо выполнить команду *git init* в папке с репозиторием. Также можно выполнить команду *git init path_to_name_dir*, что укажет на папку с репозиторием, которую мы хотим включить в контроль версий. В указанных папках создасться скрытая папка ***.git***, за счет которой будет осуществляться процедура контроля версий.

## Создание коммитов

### Git add
Для добавления изменений в коммит используется команда *git add*. Чтобы использовать команду *git add* необходимо написать _**git add <имя файла>**_

### Посмотр состояния репозитория
Для того, чтобы посмотреть сосотняие репозитория используется команда *git status*. Для этого в папке с репозиторием написать _**git status**_. Данная команда покажет - были ли изменения в файлах, или их не было.

### Создание коммитов
Для того, чтобы создать коммит(сохранение, фиксирование) необходимо выполнить команду *git commit*. Команда выполняется следующим образом: _**git commit -m "Комментарий(Message)"**_.

## Вывод на экран всех сохранений

Для того, чтобы посмотреть все изменения внесенные в репозиторий необходимо выполнить команду _**git log**_. Даннная команда покажет все изменения, который сохранены в текущий файл с коментарийми(месседжами), какие изменения проводились или сохранялись в данный файл.

## Как переходить между коммитами и смотреть в чем разница

Для того, чтобы перейти от одного коммита к другому, необходимо выполнить команду *git checkout*. Выполняется она следующим образом _**git checkout <number_or_name commit>**_. Где *number commit* - первые цифры коммита на который нужно перейти, эти цифры показывает команда *git log*:
```
commit 05ba2bf6c41f17a944c9d23a503653219cd0b1bf
Author: alex <aleks15.12@mail.ru>!
Date:   Fri Aug 23 09:45:35 2024 +0300
    How to initialzed directory
```
Для того, чтобы вернуться к актуальному состоянию и продолжить работу нужно вести команду _**git checkout master**_.

Для того, чтобы увидеть разницу между текущим файлом и закоммиченным файлом достаточно ввести команду _**git diff**_.

# Как создать новую ветку из мастера
Для того, чтобы создать новую ветку необходимо ввести команду
```
sh
git branch <branch_name>
```

# Как выполнять слияние веток
Для того, чтобы слить ветки необходимо:
1. Перейти на ветку в которую будет происходить слияние. Обычно это ветка **_master_**
```
git checkout master
git branch
```
Команда **_git branch_** показывает все ветки, которые есть у репозитория
2. Выполнить команду
```
sh
git merge <name_branch>
```
с указанием имени ветки которую хотим залить в данную ветку.

# Как удалять ветку/и
Для того, чтобы удалить созданную ветку, необходимо ввести

```
sh
git branch -d/D <branch_name>
```

# Как получить графическое представление веток, а также получить логи в одну строку
Для того, чтобы получить графическое представлние нужно ввести команду
```
sh
git log --graph
```
Для того, чтобы увидеть логи изменений в одну линию нужно ввести команду
```
sh
git log --oneline
```
Также можно комбинировать эти команды для красивого представления структуры
```
sh
git log --oneline --graph --decorate
```

## Работа с удаленными репозиториями

Для рабоыт с удаленными репозиториями желательно(необязательно) иметь аккаунт на GitHub, GitLab или другом удаленном сервере, который позволяет создавать, хранить, изменять и делиться своими репозиториями.

# Добавление файлов с удаленного репозитория
Для того, чтобы получить(кклонировать) удаленный репозиторий на свой локальный компьютер необходимо выполнить команду
```
sh
git clone <link>
```

link - ссылка на адрес, где находится репозиторий, который мы хотим получить на свой локальный компьютер.

# Внесение изменнеий на удаленый репозиторий

После работы с файлом на локалльном репозитори можно выполнить отправку изменений на удаленный репозиторий. Для этого надо сначал внести изменений на локальном компьютере
```
sh
git add <name>
git commit -m "Commit"
```
после выполнения этих команд можно выполнить команду
```
sh
git push
```
Произойдет "выталкивание" всех внесенных изменений на удаленный сервер, если выполнится команда без ошибок.
Посмотреть произошли ли изменений, можно на удаленном сервере. Обновить страницу и если произошли изменений, то соответсвенно появятся внесеные изменения.

# Как получить изменения на локальный компьютер

Если работа велась на удаленном сервере, или работают несколько человек с одним файлом, можно "притянуть" изменения, которые произошли на удаленном сервере. Для того, чтобы "притянуть" измененный файл с удаленного сервера необходимо выполнить команду
```
sh
git pull
```
После выполнения команды, появится актуальная версия файла со всеми изменениями, который были с ним произведены
