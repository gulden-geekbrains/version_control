# Подсказка по GIT

Создание репозитория:
```sh
git init
```

Переносит изменения из рабочего каталога в раздел проиндексированных файлов
```sh
git add
```

Делает фиксацию изменений
```sh
git commit -m "Message text"
```

Показывает журнал фиксаций
```sh
git log
```

Показывает журнал фиксаций в компактном виде
```sh
git log --oneline
```

Перемешение по веткам
```sh
git checkout <имя_ветки>
```

Делает слияние веток
```sh
git merge
```
Сделали слияние
Удалили ненужные ветки

Отображение всех веток
```sh
git branch
```

Создание новой ветки
```sh
git branch <имя_ветки>
```
Удаление ветки
```sh
git branch -d <branch_name>
```

Показать лог комитов с графом
```sh
git log --oneline --graph
```

# Последовательность команд в разрешении конфликтов

Сначало, переходим в мастер и сливаем в нее нужную ветку
```sh
git merge <branch_name>
```
Потом разрешаем конфликт и проверяем статус
```sh
git status
```
После добавляем файл с изменениями
```sh
git add <filename>
```
Снова проверяем статус и комитим
```sh
git commit -m ""
```

Завершили домашнее задание

Удалили ненужные ветки

Клонирование удаленного репозитория в локальную директорию:
```sh
git clone <https://github.com/. . .>
```

Создает файл README.md
```sh
echo "# practice-urok3" >> README.md
```

Инициализирует локальный репозиторий
```sh
git init
```

Индексирует файл
```sh
git add <file>
```

Фиксирует изменения
```sh
git commit -m "first commit"
```

Переименование текущей ветки
```sh
git branch -M <main>
```

Ставит в качестве удаленного репозитория по умолчанию
```sh
git remote add origin <https://github.com/VtkVatakat/>practice-urok3.git>
```

Отправляет все изменения в удаленный репозиторий по умолчанию, в ветку main
```sh
git push -u origin main
```

Показывает подробную информацию про удаленный репозиторий
```sh
git remote show origin
```

Скачивает изменения с удаленного репозитория
```sh
git pull
```

Отправляет изменения на удаленный репорзиторий
```sh
git push
```

Отправляет ветку на удаленный репозиторий, передти на отправляемую ветку
```sh
git push --set-upstream origin newbranch
```

Удаление ветки с удаленного репозитория
```sh
git push origin --delete <branch_name>
```

## Последовательность решения конфликта между удаленным репозиторием и локальным

Если есть конфликт, то сначало нужно скачать изменения с удаленного репозитория и произвести слияние с нашими текущими изменениями
```sh
git pull --rebase
```

Потом отредактировать конфлик

И продлжить слияние
```sh
git rebase --continue
```
