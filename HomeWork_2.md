# Руководство по GIT

## *Команды терминала git:*

* **Команда** инициализирует новый репозиторий GIT и начинает отслеживание существующего каталога:
```sh
git  init
```
* **Команда** добавляет изменение из рабочего каталога в раздел проиндексированных файлов:
```sh
git add
```
* **Команда** делает снимок состояния проекта на текущий момент времени с внесением пояснения, что именно изменилось:
```sh
git commit -m "message"
```
* **Команда** для просмотра текущего изменения между ветками созданными ранее:
```sh
git diff
```
* **Команда** отображает отправленные снимки состояния и позволяет просматривать и фильтровать историю проекта, а также искать в ней конкретные изменения:
```sh
git log
```
* **Команда** показывает хеш в укороченном формате, ветку, в которой сделан коммит, а также текст коммита:
```sh
git log --oneline
```
* **Команда**, которая позволяет нам переключаться между ветками, перемещаться по коммитам, восстанавливать файлы из предыдущих состояний и не только:
```sh
git checkout
```
* **Команда** позволяющая вернуться на ветку мастер:
```sh
git checkout master
```

* **Команда** Позволяющая посмотреть все ветки:
```sh
git branch
```
* **Команда** для просмотра лога нескольких веток в сокращенном формате:
```sh
git log --oneline --graph
```
 * **Команда** позволяющая создавать новые ветки:
 ```sh
 git branch <branch_name>
 ```
 * **Команда** позволяющая выполнить слияние веток:
 ```sh
 git merge
 ```
 * **Команда** позволяющая удалить метки ранее созданных меток:
 ```sh
 git branch -d <branch_name>
 ```
