# Как работать с удаленными репозиториями с GitHub

По началу нам надо создать репозиторий на гитхабе после чего создать папку командой
```sh
mkdir
```

После чего инициализоровать в папке Git командой
```sh
git init
```

После чего прописать подсказки команды в терминале чтобы дать толчок продвижению проекту

Как опубликовать изменения онлайн

```sh 
git push
```

Как загрузить изменения локально на компьютер
```sh
git pull
```

Как создать клон репозитория на своем компьютере
```sh
git clone <сыллка>
```

Как исправить конфликт (две команды)
```sh
git pull --rebase
```

После разрешения конфликта в VSCODE, прописать данную команду чтобы уже толкнуть к загрузке на гитхаб

```sh
git rebase --continue
```
