## Подробная инструкция по клонированию репозитория, внесению правок в отдельной ветке и созданию Pull Request через PyCharm:

**1. Клонирование репозитория:**

* **Открываем PyCharm и выбираем "Get from VCS":**  В начальном окне PyCharm выберите "Get from VCS".  Также можно использовать меню `File` -> `New` -> `Project from Version Control`.
* **Вводим URL репозитория:** В поле "URL" вставьте URL репозитория GitHub, который вы хотите клонировать.  Можно использовать SSH или HTTPS URL.
* **Выбираем директорию:**  Укажите директорию, куда вы хотите клонировать репозиторий.
* **Нажимаем "Clone":** PyCharm скачает репозиторий на ваш компьютер.


**2. Создание новой ветки:**

* **Открываем окно "Git":**  В PyCharm внизу справа найдите вкладку "Git" (если её нет, откройте через `View` -> `Tool Windows` -> `Git`).
* **Нажимаем на имя текущей ветки (обычно `main` или `master`):**  Откроется меню.
* **Выбираем "New Branch":**  Введите название новой ветки (например, `my-feature` или `fix-bug`) и нажмите "OK".


**3. Внесение правок:**

* **Редактируем файлы:**  Вносите необходимые изменения в файлы проекта.  PyCharm подсветит измененные файлы.


**4. Коммит изменений:**

* **Открываем вкладку "Local Changes" в окне "Git":** Здесь отображаются все внесенные изменения.
* **Выбираем файлы для коммита:**  Отметьте галочками файлы, которые хотите включить в коммит.
* **Пишем комментарий к коммиту:**  В поле "Commit Message" напишите краткое и понятное описание внесенных изменений.
* **Нажимаем "Commit":**  PyCharm зафиксирует ваши изменения в локальном репозитории.


**5. Отправка ветки на GitHub (Push):**

* **Нажимаем "Push" в окне "Git" (или используем сочетание клавиш Ctrl+Shift+K):**  PyCharm отправит вашу ветку на GitHub.


**6. Создание Pull Request:**

* **Открываем GitHub в браузере:** Перейдите на страницу репозитория, который вы клонировали.
* **GitHub предложит создать Pull Request:**  После push'а новой ветки, GitHub обычно отображает баннер с предложением создать Pull Request.  Если его нет, перейдите во вкладку "Pull requests" и нажмите кнопку "New pull request".
* **Выбираем ветки:**  Убедитесь, что в качестве "base branch" (ветка, в которую вы хотите внести изменения) выбрана `main` (или `master`) оригинального репозитория, а в качестве "compare branch" (ветка с вашими изменениями) выбрана ваша ветка (например, `my-feature`).
* **Указываем ссылку на ваш репозиторий (если нужно):** Если вы хотите, чтобы автор посмотрел ваш код в вашем репозитории (а не только в Pull Request'е), добавьте ссылку на ваш репозиторий в описание Pull Request'а.  **Важно:**  Убедитесь, что ваш репозиторий публичный, иначе автор не сможет его увидеть.  Ссылка должна указывать на вашу ветку с изменениями, например: `https://github.com/<ваш_логин>/<ваш_репозиторий>/tree/<название_ветки>`.
* **Пишем описание Pull Request'а:**  Опишите внесенные изменения, их цель и почему они полезны.
* **Нажимаем "Create pull request":**  Ваш Pull Request будет отправлен автору оригинального репозитория.


**Пример ссылки на ваш репозиторий (заранее подготовленный):**

```
Мой код с изменениями доступен по ссылке: https://github.com/YourUsername/YourRepository/tree/my-feature
```

Замените `YourUsername`, `YourRepository` и `my-feature` на ваши данные.  Убедитесь, что ветка `my-feature` существует в вашем репозитории и содержит ваши изменения.  Также убедитесь, что ваш репозиторий публичный.


Теперь автор оригинального репозитория сможет просмотреть ваш Pull Request, оставить комментарии и принять ваши изменения.
