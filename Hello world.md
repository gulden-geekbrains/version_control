## Выделение текста

Для выделения текста курсивом обрамите его звездочками - 
*Курсив.*

Для выделения текста полужирным обрамите его двойными звездочками - 
**Полужирный.**

Для выделения текста сразу обоими стилями обрамите его тройными звездочками -
***Жирный***

Для выделения зачеркнутого текста обрамите его тильдой -
`Зачеркнутый текст`

## Списки

Для создания ненумерованного списка необходимо выделить начало строки звездочкой и поставить пробел -
* Элемент 1
* Элемент 2
* Элемент 3

Для создания нумерованного списка необходимо начать список с цифры с точкой -
1. Первый элемент нумерованного списка
2. Второй элемент немерованного списка

 # Подсказка по Git 

Создание репозитория:
```sh
git init
```
Добавить к индексации:
```sh
git add
```
Зафиксировать изменения:
```sh
git commit -m "Message text"
```
Посмотреть log в полном виде:
```sh
git log
```
Посмотреть log в сокращенном виде:
```sh
git log --oneline
```
Посмотреть log в сокращенном виде по графам:
```sh
git log --oneline --grapg
```
Перемещение по веткам:
```sh
git checkout <имя ветки> 
```
Отображение всех веток
```sh
git branch
```
Создание новой ветки:
```sh
git branch <имя_ветки>
```
Удаление созданой ветки:
```sh
git branch -d <имя ветки>
```
