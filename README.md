# Это репозиторий для обучения pull request

## Первые шаги

1. Делаем fork репозитория, в которой потом хотим сделать pull request. Ищем кнопку Fork на странице репозитория <https://git@github.com:gulden-geekbrains/version_control.git>
2. Выполняем команду клонирования из своей fork-копии
```sh
git clone git@github.com:*YOURE_GITHUB*/version_control.git
```
3. Создаем новую ветку и вносим необходимые изменения в файл
```sh
git checkout -b updatereadme
vim README.md
git add README.md
git commit -m "Добавили инструкцию как создать pull request"
```
4. Делаем push  
```sh
git push --set-upstream origin updatereadme
```
5. Переходим на свою страницу репозитория. Выбираем ветку **updatereadme** и жмем кнопку **Compare & pull request**

## Заметки

Что бы сделать push от другого пользователя необходимо выполнить команду
```sh
GIT_SSH_COMMAND='ssh -i ~/.ssh/user-private-key -o IdentitiesOnly=yes' git push git@github.com:gulden-geekbrains/version_control.git
```

вместо *user-private-key* подставьте свой ключ

Можно прописать настройки для подсоединения по ssh
```sh
git config remote.origin.url git@github.com:gitusername/reponame
git config core.sshCommand "ssh -i ~/.ssh/user-private-key -o IdentitiesOnly=yes"
```

Вот инструкция по созданию Pull Request на платформе GitHub:

1. Форкните репозиторий: Перейдите на страницу репозитория, в который вы хотите внести изменения, и нажмите кнопку "Fork" в правом верхнем углу экрана. Это создаст копию репозитория на вашем аккаунте.
2. Клонируйте форкнутый репозиторий: Склонируйте ваш форкнутый репозиторий на ваш локальный компьютер с помощью команды git clone.
3. Создайте новую ветку: Перейдите в склонированный репозиторий на вашем компьютере с помощью команды cd, а затем создайте новую ветку, в которой вы будете вносить изменения, с помощью команды git checkout -b <название_ветки>.
4. Внесите изменения: Внесите необходимые изменения в код, добавьте новые файлы или отредактируйте существующие.
5. Закоммитьте изменения: Добавьте ваши изменения в индекс с помощью команды git add, а затем закоммитьте их с помощью команды git commit.
6. Отправьте изменения в ваш форкнутый репозиторий: Отправьте вашу ветку с изменениями на GitHub с помощью команды git push origin <название_ветки>.
7. Создайте Pull Request на GitHub: Перейдите на страницу вашего форкнутого репозитория на GitHub. GitHub обнаружит, что вы только что отправили новую ветку, и предложит создать Pull Request. Нажмите на кнопку "Compare & pull request".
8. Опишите Pull Request: Дайте вашему Pull Request название и описание, объясняющее, какие изменения вы внесли и почему они важны.
9. Отправьте Pull Request: Нажмите на кнопку "Create pull request", чтобы отправить ваш Pull Request.
10. Ожидайте рецензии: Теперь ваш Pull Request отправлен в репозиторий и доступен для рецензии другими участниками проекта. Ожидайте комментариев и обратной связи.
11. Внесите изменения по запросу рецензента: Если рецензент запросит изменения, внесите их в вашей ветке и отправьте обновленный Pull Request.
12. Merge Pull Request: После того как ваш Pull Request будет принят и проверен, администратор проекта может смерджить его в основную ветку репозитория.
