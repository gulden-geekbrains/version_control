# *Синтаксис языка MarkDown*

## Команды:

#### 1. Инициализация репозитория.

```sh
git init 
```
* ***С помощью этой команды Git начнет отслеживать нашу папку.***

#### 2. Добавление содержимого файла.
```sh
git add
```
* ***С помощью этой команды Git добавит содержимое рабочего каталога для последующего коммита.***

 #### 3. Добавление комментария об изменениях и запись всех измененных данных.
```sh
git commit -m "text"
```
* ***С помощью этой команды Git берет все данные, добавленные с помощью git add и сохраняет их во внутреннюю базу данных.***

#### 4. Развернутый журнал всех сохраненных изменений.
```sh
git log
```
* ***С помощью этой команды можно отследить все изменения структуры проекта с указанием автора и времени изменения.***

#### 5. Краткий журнал всех сохраненных изменений.
```sh
git log --oneline
```
* ***С помощью этой команды можно найти и отследить все изменения структуры проекта более быстро.***

#### 6. Команда выбора определенной версии проекта.
```sh
git checkout
```
* ***Эта команда позволяет вернуться к любой выбранной версии при указании ее идентификатора если у вас есть только одна ветка проекта.***

#### 6.1 Выбор необходимой, для работы, ветки
```sh
git checkout <имя ветки>
```
  * ***Так же команда checkout позволяет выбрать нужную ветку проекта.***

#### 7. Текущее состояние GIT
```sh
git status
```
* ***С помощью этой команды можно увидеть есть ли несохраненные изменения.***

#### 8. Отображение изменений
```sh
git diff
```
  * ***Эта команда показывает разницу между текущим файлом и предыдущей его версией.***

#### 9. Отобразить все имеющиеся ветки
```sh
git branch
```
  * ***Эта команда показывает все созданные ветки.***

#### 10. Создание новой ветки
```sh
git branch <имя ветки>
```
  * ***Эта команда новую ветку.***
  
#### 11. Слияние веток
```sh
git merge <имя ветки>
```
  * ***Эта команда присоединяет выбранную ветку к той, в которой мы находимся.***

#### 12. Отображение ветвления в истории изменений
```sh
git log --graph
```
или
```sh
git log --oneline --graph
```

  * ***Эта функция позволяет увидеть ветвление в истории всех изменений проекта.***

### 13. Удаление веток
```sh
git branch -d <имя ветки>
```
  * ***Эта команда позволяет удалить лишние ветки, после их присоединения к основной.***

   Прим. Основная ветка всегда 'masters'

# *Оформление текста в языке MarkDoun*

#### 1. Для создания заголовка, необходимо использовать символ (#):

*Пример:*

 * # Заголовок первого уровня.

 * ## Заголовок второго уровня.

 * ### Заголовок третьего уровня.

#### 2. Для написания текста полужирным, курсивом или зачеркнутым:

*Пример:*

 - **Две звездочки или два знака нижнего подчеркивания с двух сторон строки - полужирный** 

- *Одну звездочку или один знак нижнего подчеркивания с двух сторон строки - курсив*

- ~~По две волны с двух сторон~~

 Для написания полужирного курссива можно комбинировать эти знаки в одном тексте:

 *Пример:*

_Полужирный ~~зачеркнутый~~ **Курсив**_

### 3. Списки

#### Не нумерованый список:

  * (*),(-) или (+) в начале строки.

  * Подсписок - отступ, (*),(-) или (+).

 #### Нумерованный список: 

 1. Цифра, точка, далее обычный текст.
 2. и т.д.

 ### 4. Варианты цитирования.

 Используя символ (>) можно оформить цитаты.

 *Пример:*

> Цитирование
>> Двойная сноска цитаты.

### 5. Web ссылки

Чтобы создать веб-ссылку необходимо написать:
Текст описание, далее в квадратных скобках пишем название, далее в круглых скобках пишем адрес сайта.

*Пример:* Перейти на сайт [Туркомплекс "Причал"](http.prichalrk.ru) 

### 6. Добавление картинок в MarkDown

#### Для того что бы добавить картинку: 

![всплывающая подсказка] (название картинки с расширением)

*Пример:* ![Эскиз](8.jpg)
