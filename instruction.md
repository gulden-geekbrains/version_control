## Команды для работы с удаленным репозиторием:

```sh
git clone <адрес репозитория>
```
скопирует файлы удаленного репозитория в локальный на ваш пк


```sh
git remote add origin <ссылка на репозиторий>
```
укажет адрес в github, куда в дальнейшем будет заливаться код в интернет.


```sh
git branch -M main 
```
переименует ветку master  в main, и укажет терминалу git, что данная ветвь
теперь основная  в проекте.

```sh
git push -u origin main 
```
зальет код изменений в репозиторий на github

```sh
git pull 
```
синхронизирует,'подтянет' состояние с удаленного репозитория на локальный

```sh
git pull - rebase
```
вначале скачает репозиторий из сети интернет, затем попытается слить ветви.

```sh
git push origin --delete <имя ветви>
```
удалит из удаленного репозитория данную ветвь
