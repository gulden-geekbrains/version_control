# Подсказка по Git

Создание репозитория:
```sh
git init
```

Перенос изминений из рабочего коталога в раздел проиндексированных файлов:
```sh
git add (имя)
```

Снимок текущего состояния изменений добавленных в раздел проиндексированных файлов:
```sh
git commit -m "Messege"
```

Отображает  состояние отправленных снимков позволяет филтровать историю проекта а также искать изминения:
```sh
git log
```

Показывает кеш в укороченном формате в котором сделан commit:
```sh
git log --oneline
```

переход сохранению,преключение между файлами
```sh
git checkout (код файла)
```

Выводит все ветки которые были созданы и (*)указывает ветку где распологаемся:
```sh
git branch
```

Очищает терминал:
```sh
clear
```
Cоздание новой ветки:
```sh
git branch new_branch_name
```
Переход с одной ветки на другую
```sh
git checkout (имя ветки)
```
Создаёт новую ветку переключаясь на неё
```sh
git checkout -b (new branch name)
```

Слияние
```sh
git merge
```
Слияние веток в ветку master
```sh
git merge (имя ветки)
```
Удаление ветки
```sh
git branch -d (имя ветки)
```
Вывод дерева всех комитов
```sh
git log --graph
```

Показывает разницу,отличие файлов в комите
```sh
git dif
```
Вывод дерева всех коммитов.
```sh
git log --graph
```
Клонирует интересуещий нас репозиторий.
```sh
git clone
```
Переход по веткам на уровень выше.
```sh
cd ..
```
Переименовывает ветку *master* в *main*
 ```sh
 git branch -M main
 ```
 В качестве удолённого репозитория по умолчанию,делаем новый репозиторий с GitHub.Cвязывает локальный репозиторий с удолённым.
 ```sh
 git remote add origin (https://)
 ```
Информация об удщлённом репозитории.
```sh
git remote show
```
Более подробная информация об удалённом репозитории.
```sh
git remote show origin
```
Локальный репозиторий выталкивает на сервер
```sh
git push 
```
Стягивает все изменения с удалённого репозитория в локальный репозиторий.
```sh
git pull
```
Удаляем ветку в __GitHub__
```sh
git push origin --delete (имя ветки)
```
Делает выкачку и слияние с нашим текущим изминением.
```sh 
git pull --rebase
```
# *Работа с удолённым репозиторием*

## Как делать *Pull reguest*

1. Делаем *fork*-(вилка) с интересуещего нас акаунта,с итересующим нас репозиторием в свой акаунт.После чего копируем ссылку данного репозитория в своём акаунте.

2. Делаем *git clone* нашей версии данного репозитория.

3. Создаём ветку в *git* с предлогаемыми своими изминениями.

4. ### Производим изменения только в созданной нами ветке!

5. Делаем *push*-(толкать,отправлять).Отправляем эти изминения на свой акаунт.

6. В своём акаунте делаем *pull reguest*-(тянуть,регестрировать) и отпровляем наше изминения.
