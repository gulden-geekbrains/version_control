# Первый урок по GIT

Инициализация пустого git
```sh
git init
```
Команды для сохранения изменений в репозитории
```sh
git add "file name"
git commit -m "инициализировали гит"
```
Просмотр версий проекта
```sh
git log (--oneline),(graph)
```
Перемещение по версиям проекта
```sh
git checkout "коммит"
```

## Второй урок. Работа с ветками

Просмотр и создание ветки
```sh
git branch
git branch "имя ветки"
```
Перемещение по веткам
```sh
git checkout "имя ветки"
```
Удаление ветки
```sh
git branch -D "Имя ветки"
```
Как слить ветки воедино
```sh
git merge "название ветки"
```
Изменение названия ветки
```sh
git branch -M "Название ветки"
```

# Последний урок. Работа с удаленными репозиториями

Клонирование репозитория из github к себе
```sh
git clone "Путь к github репозиторию.git"
```
Добавление локального проекта в удаленный репозиторий (в Github)
```sh
git remote add origin ссылка на репозиторий
```
Оканчательное внесение изменений в удаленный репо
```sh
git push -u origin main
```
Всосать данные из удаленного репо в свой локальный репо
```sh
git pull
```
