# Подсказка по Git

## 1. Инициализация репозитория

```sh
git init
```
- Инициализирует новый репозиторий Git в текущем каталоге.

## 2. Добавление файла
```sh
git add [file]
```
- Добавляет указанный файл в индекс (для отслеживания изменений).

## 3. Фиксация состояиния
```sh
git commit -m "Сообщение коммита"
```
- Фиксирует текущее состояние индекса в истории репозитория с сообщением.

## 4. Текущий статус
```sh
git status
```
- Показывает текущее состояние рабочей директории и индекса.

## 5. Список локальных веток
```sh
git branch
```
- Показывает список локальных веток. Для создания новой ветки используйте `git branch [название]`.

## 6. Переключение веток
```sh
git checkout [ветка]
```
- Переключается на указанную ветку.

## 7. История коммитов
```sh
git log
```
- Показывает историю коммитов.

## 8. Клонирование репозитория 
```sh
git clone [url]
```
- Клонирует репозиторий с указанного URL на локальную машину.

## 9. Получить изменения
```sh
git pull
```
- Вытягивает изменения из удаленного репозитория и объединяет их с текущей веткой.

# 10. Отправить изменения
```sh 
git push
```
- Отправляет локальные изменения на удаленный репозиторий.
