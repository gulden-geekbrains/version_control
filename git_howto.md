# Подсказка по гиту

## Инициализация репозитория

```sh
git init
```

## Статус репозитория

```sh
git status
```

1. start - **git init**
2. status - **git status**
3. add - **git add**
4. save - **git commit**
5. version - **git checkout $version**
6. actual version - **git checkout master**
7. compare - **git diff**
8. get repo - git pull
9. give repo remote - git push
