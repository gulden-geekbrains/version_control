# Подсказка по гиту

## Инициализация репозитория

```sh
git init
```

## Статус репозитория

```sh
git status
```

# Подсказки по командной строке

Команда смены директории
```sh
cd c:\folder_name
```

Команда отображения
текущей директории. MacOs and Linux
```sh
pwd
```

Листинг текущей директории. Windows:
```sh
dir
```
Linux, MacOs:
```sh
ls
```

Удаление файла в Windows:
```sh
del <filename>
```

Удаление файла в MacOs, Linux:
```sh
rm <filename>
```

Инициализация локального репозитория
```sh
git init
```

Получение информации от git о его текущем состоянии
```sh
git status
```

Добавление файлов к следующему комиту
```sh
git add <doc_name>
```

Зафиксировать изменения
```sh
git commit -m '<comment>'
```

Отображение всех веток
```sh
git branch
```

Перемещение по веткам
```sh
git checkout <branch_name>
```

Создание новой ветки
```sh
git brach <branch_name>
```

Удаление ветки
```sh
git branch -d <branch_name>
```

Посмотреть изменения в коде
```sh
git diff
```

Вывод на экран истории всех коммитов
```sh
git log
```
Визуализация комитов
```sh
git log -- graph
```
Слияние веток
```sh
git merge <имя_ветки>
```
