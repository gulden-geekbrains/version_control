# Подсказка по гиту

## Инициализация репозитория

```sh
git init
```

## Статус репозитория

```sh
git status
```

## Команды для Git. Удаленный репозиторий

Клонирование удаленного репозитория

**git clone**

Отправка изменений в удаленный репозиторий

**git push**

Получение изменений из удаленного репозитория

**git pull**
