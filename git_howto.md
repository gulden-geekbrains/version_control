# GIT instruction

## GIT commands

```sh
git init
```
Start traking a directory

```sh
git add <file_name>
```
Adding the specified file to the GIT index

```sh
git commit -m 'message'
```
Commit changes to the repository

```sh
git log
```
Commit log list.

```sh
git log --oneline
```
Abbriviated form

```sh
git checkout <branch_name>
```
Switch between branches

```sh
git branch <branch_name>
```
Branch display

```sh
git branch -d <branch_name>
```
Branch removal

```sh
git log --oneline --graph
```
Tree view.

```sh
git status
```
Status display

```sh
git merge
```
Branch merge

```sh
git push
```
Sends commits from the local repository to the remote repository

```sh
git pull
```
Updates the local repository by pulling changes from the remote repository
