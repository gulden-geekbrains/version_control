# Подсказка по гиту

## Инициализация репозитория

```sh
git init
```

## Статус репозитория

```sh
git status
```

## Версия Git

```sh
git --version
```

## Добавление файла в репозиторий 

```sh
git add
```

## Сохранение с сообщением 

```sh
git commit -m "Commit message"
```

## История коммитов 

```sh
git log
```

## Открывает конкретное сохранение 

```sh
git checkout <commit>
```

## Открывает конкретную ветку 

```sh
git checkout <branch_name>
```

## Показывает разницу между послдней закомиченной версией и текущей 

```sh
git diff
```

## Показывает какие ветки есть и на какой мы сейчас находимся 

```sh
git branch
```

## Заливает выбранную ветку в ту на которой сейчас находимся

```sh
git merge <branchname>
```

## Создать локальный репозиторий из гитхаба

```sh
git clone [url]
```

## Отправить версию в интеренет 

```sh
git push
```

## Скачать актуальну юверсию из интеренета 

```sh
git pull
```
