# Подсказка по git

## Инициализирует новый Git-репозиторий в текущей директории
```sh
git init
```
## Добавляет изменения (файлы) в индекс для следующего коммита
```sh
git add
```
## Фиксирует добавленные изменения с сообщением "Comment"
```sh
git commit -m "Comment"
```
## Показывает историю коммитов в репозитории
```sh
git log
```
## Выводит краткую историю коммитов в одну строку на каждый
```sh
git log --oneline
```
## Переключается между ветками или восстанавливает файлы из истории
```sh
git checkout <имя_ветки>
```
## Показывает список всех локальных веток. Текущая ветка будет выделена звездочкой (*).
```sh
git branch
```
## Сливает указанную ветку в текущую. 
```sh
git merge
```
## Удаляет ветку
```sh
git branch -d "имя ветки"
```


## Клонирует удалённый репозиторий на локальную машину.
```sh
git clone <URL>
```
## Показывает список подключённых удалённых репозиториев и их URL.
```sh
git remote -v
```
## Загружает изменения из удалённого репозитория, но не сливает их с локальной веткой.
```sh
git fetch <remote>
```
## Отправляет изменения из локальной ветки в удалённый репозиторий.
```sh
git push <remote> <branch>
```
## Загружает изменения из удалённой ветки и автоматически сливает их с текущей локальной веткой.
```sh
git pull <remote> <branch>
```
