# Работа с удаленными репозиториями

Если для работы с локальными репозиториями достаточно VS Code и Git, то для работы с удаленными репозиториями необходимо "подружить" их с еще одним сервисом по названием GitHub. С помощью него можно вносить изменения в удаленный репозиторий с лакального и наоборот, подгружать себе уже существующие репозитории и их актуальные изменения. Рассмотрим.

## Git push

Если у нас имеется репозиторий, который необходимо сделать удаленным, нужно:

1. Сделать основной веткой main. Для этого используем команду:

```sh
git branch -M main
```

2. Далее нужно указать адрес удаленного репозитория, куда будет скопирован локальный(для этого пользователь обязательно должен быть авторизирован):

```sh
git remote add origin ссылка
```

3. И завершающий шаг, отправка репозитория на сервер:

```sh
git push -u origin main
```

Команда сообщает, что необходимо загрузить локальный репозиторий в удаленный (origin) в ветку main

В дальнейшем можно использовать только **git push**, так как путь мы уже указали.

## Pull request

Это действие предполагает, что мы внесли изменение в копию репозитория другого разработчика и предлагаем ему рассмотреть наш вариант решения задачи, отправляя ему его.

Для начала нужно сделать копию репозитория в наш аккаунт. Это можно сделать с помощью кнопик **fork**. Далее мы подгружаем с помощью **clone** эту копию и делаем из нее локальный репозиторий. Создаем новую ветку, в которую вносим нужные изменения и выталкиваем эту ветку в нашу копию удаленного репозитория с помощью команды:

```sh
git push --set-upstream origin названиеветки
```

После этого в нашем удаленном репозитории появится ветка с локального репозитория, а также появится кнопка _**compare&pull request**_, с помощью которой мы и предложим наши изменения автору репозитория
