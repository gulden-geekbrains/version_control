# Команды для Git

```sh
git init - инциализация репозитория
```

![innit](init.jpg)

```sh
git add - отслеживать добавленный файл
```

![add](add.jpg)

```sh
git commit -m "(коментарий к комиту)" - добавить комит.
```

![commit](commit.jpk.jpg)

```sh
git log - показать список комитов
```

![log](log.jpg)

```sh
git checkout (хеш комита) - вернутся к выбранному комиту 
```

![checkout](checkout.jpg)

```sh
git diff (хеш комита) - показать резницу между текущим и выбранным комитом
```

![diif]( diff.jpg)

```sh
git ststus - показать статус текущего файла
```

```sh
git branch (название ветки) - добавить новую ветку в репозиторий 
```

```sh
git checkout (название ветки) - переключиться на другую ветку 
```

```sh
git merge (название ветки) - слияние текущей ветки с указанной в команде
```

```sh
git branch -d (название ветки) - удалаить указанную ветку
```

```sh
git ignore (название файла) - игнорировать указанный файл
```

```sh
git log --graph - показать древо комитов
```

Еще больше команд можно посмотреть по [ссылке](https://habr.com/ru/companies/ruvds/articles/599929/ "Нажми на меня")

## Команды для работы с удаленным репозиторием 

```sh
git clone (URL удаленного репозитория)- копирует удаленный репозиторий в локальный 
```

```sh
git push - вносит изменения из локального репозитория в удаленный 
```

```sh
git pull - вносит изменения из удаленного репозитория в локальный.
 (--rebase) ключь который позволяет внести изменения созданные в удаленном репозитории с локальными 
```
