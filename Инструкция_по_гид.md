## Инциализирует гит в папке:
```sh
git init 
```

## Добавление файла:

```sh
git add
```

## Сохранение текущих изменений и создание отметки:

```sh
git commit -m "massage"
```

## Просмотр сохранений и отметок:
```sh
git log ;
git log --oneline
```

## Переключение между сохранениям:

```sh
git checkout 
```

## Разница между текущей версий файла и последним сохранением; разница между сохранениями:

```sh
git diff
```

## Просмотр всех веток и создание новой ветки:
Например, git branch <Название ветки>.

```sh
git branch
```

## Удаление ненужной вам ветки:

```sh
git branch -d <название_ветки>
```

## Переход на нужную вам ветку:

```sh
git checkout <название_ветки>
```

## Вывод дерева веток:

```sh
git log --oneline --graph
```

## Слияние веток 
Cначала необходимо перейти в ту ветку, в которую вы хотите присоединить какую-либо ветку

```sh
git merge <Название ветки>
```

## GitHub

1. Создали акк на Github.com 
2. Создать локальный репозиторий
3. Отправить локальный репозиторий в удаленный (На Github.com) Вся инструкция есть на сайте, команда **git push**
4. Проивести изменения с другого устройства (с сайта)
5. Скачать (выкачать) изменения на локальный репозиторий, команда **git pull**

## Работа с чьими-то репозиториями 

1. Делаем форк (Fork) интересующего нас репозитория
2. Делаем git clone для нашей версии репозитория
3. Создаем ветку с предполагаемыми изменениями
4. Производим все изменения только на этой ветке
5. Отправляем все изменения на свой аккаунт git pull
6. В окне на Github появляется позможность отправить pull request

## Скопировать чей-то репозиторий 
```sh
git clone <Ссылка с источника>
```
