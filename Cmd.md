# Подсказки по командной строке 

команда смены директории 
```sh
cd c\folder_name
```

команда отображения директории
```sh
pwd
```

листинг текущей директории
Windows
```sh
dir
```

удаление файла
```sh
del<file name>
```

команда просмотра деёствий
```sh
git log  
```

команда открывающаяя изменения внесённые.
```
git diff 
```
Удаляет изменения до уровня последнего сохранения в git
```sh
git restore <имя файла> 
```
