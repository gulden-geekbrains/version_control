# подсказка по git 

создание репозитория
```sh 
git init 
```

добавить изменения 
```sh
git add
```

создание коммита (добавление новой информации и ее название)
```sh 
git commit -m "message"
```

текущее состояние 
```sh
git status
```

история всех коммитов с их хеш-кодами 
```sh
git log
```

отображение коммитов в укороченном виде (самый верхний- самый последний)
```sh
git log --oneline
```

переключение на определенный коммит
```sh
git checkout и 7 символов из коммита
```

возвращает на самое последнее состояние 
```sh
git checkout master
```

разница между текущим файлом и закоммиченным
```sh
git diff
```
