## Работа с удаленными репозиториями.
**GitHUB** - для работы с удалёнными репозиториями для начала нужно зарегистрироваться на сайте *https://github.com/*, а затем можно будет работать с удалёнными репозиториями в программе Git.

**README** - файл который должен присуствовать в каждой работе, для упрощения работы с другими людьми, в нём содержится краткое описание содержания вашего репозитория, формат файла обычно *.TXT*, для того, чтобы его можно было прочитать в любом случае так как все средства семейства Windows а также другие ОС обладают стандартным программным обеспечением для чтения текстовых форматов *.TXT*, при работе с программой git или другими может быть использован другой формат например *Markdouwn*

**git branch -M "Имя главной ветки"** - указание названия основного репозитория с которым будем работать (переименование главной ветки).

**git remote add "Имя связывающей команды" "Cсылка для связывания"** - команда инициализирущая связь с сайтом GitHUB для передачи или выгрузки репозиториев. В графе 

"Имя связывающей команды" - присвается название для связи с аккаутом на GItHUB таких связей может быть несколько. 

"Ссылка на связывание" - сюда указывается адрес или токен которому мы будем обращаться, чтобы получить доступ к аккаунту на GitHUB. При первом обращении GitHUB попросит пользователя связать свою программу Git и аккаунт на сайте.

**git push -u "Имя связывающей команды" "Имя главной ветки"**  - Данная команда отправляет ваш последний локальный репозиторий на сайт GitHub. После первой инизализации команды её можно сокращённо писать как **git push**

**git pull** - Для выгрузки данных с сайта или источника к которому у вас поключён git.

**git clone "Ссылка для связывания"** - Данная команда выгружает чужой репозиторий, предварительно для работы сним его нужно привязать а ккаунту через "Fork" на сайте GitHUB.
