# Подсказки по командной строке

Команда смены директории 
```sh
cd c:\folder_name
```

Команда отображения текущей директории. MacOs, Linux
```sh
pwd
```
Листинг текущей директории Windows:
```sh
dir
```
Листинг текущей директории MacOs, Linux:
```sh
ls
```
Удаление файла в Windows: 
```sh
del <filename>
```

Удаление файла в MacOs, Linux: 
```sh
rm <filename>
```
# **Мое руководство пользователя по Git**

Git - это специальная программа, которая позволяет отслеживать любые изменения в файлах, хранить их версии и оперативно возвращаться в любое сохраненное состояние.

## **Описание команд Git**

1. **git init** - создать репозиторий в папке на локальной машине. 

2. **git add** - отслеживать добавленные файлы.

3. **git commit** - сохранить текущее состояние, с добавлением комvентария.

4. **git log** - вызывать список действий и сохранений.

5. **git diff** - показать разницу между разными файлами.

6. **git checkout** - переключиться между разными версиями.

7. **git branch** - вывести список веток в репозитории.

8. **git checkout branch** - перейти на ветку *branch_name*.

9. **git checkout branch -d *name*** - удалит ветку, вместо *name* имя ветки.

10. **git checkout branch_name** - перейти на ветку *branch name*.

11. **git log-graph** - вывести список коммитов в виде графа/дерева. 

12. **git merge** - объеденить две ветки.

13. **git-push** - отправить изменения в удаленный репозиторий.

14. **git-pull** - подтянуть в локальный репозиторий последнюю версию файла.

15. **git-clean** - удалить не отслеживаемые файлы из рабочего каталога.

16. **git-status** - показать состояние файлов в рабочей директории и индексе.

17. **git-rm** - удалить файл из индекса и рабочей директории.

18. **git-clone <url-адрес репозитория>** - клонирование внешнего репозитория на локальный ПК.
